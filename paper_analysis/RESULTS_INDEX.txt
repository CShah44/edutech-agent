🔬 METRIC DEFINITIONS QUICK REFERENCE
================================================================================

LLM-BASED:
├─ Answer Accuracy (0-1): Direct correctness judgment by LLM
├─ Correctness (0-10): How correct the content is
├─ Completeness (0-10): How complete the answer is
└─ Overall (0-10): Combined quality score

LEXICAL OVERLAP:
├─ BLEU: Bilingual evaluation understudy (n-gram precision)
├─ CHRF: Character n-gram F-score
├─ ROUGE: Recall-oriented understudy for gisting evaluation
│  ├─ ROUGE1: Unigram overlap
│  ├─ ROUGE2: Bigram overlap
│  └─ RougeL: Longest common subsequence
└─ All: Higher = more similar to reference

SEMANTIC:
├─ BERT-Score: Contextual embeddings (P/R/F1)
├─ Similarity (sim_max/mean/min): All-MiniLM-L6-v2 embeddings
└─ Higher = more semantically similar

LANGUAGE MODEL:
├─ Perplexity (GPT-2): How "expected" text is (lower = more expected)
└─ Higher = more novel/unusual generation
