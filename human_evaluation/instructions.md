# Human Evaluation Instructions

## Task Overview

You are evaluating **ELI5 (Explain Like I'm 5) answers** generated by two different AI systems. For each question, you will see:

- **The question** (a real question from the ELI5 dataset)
- **Answer A** (generated by one system)
- **Answer B** (generated by the other system)
- **Reference answer** (human-written answer for context)

**Important:** The order of Answer A and Answer B is randomized. You do not know which system generated which answer. This is a **blind evaluation**.

---

## Your Task

For each sample, rate **both Answer A and Answer B** on four dimensions using a **1-5 scale**.

### Scoring Dimensions

| Dimension | What to Evaluate |
|-----------|------------------|
| **Accuracy** | Is the answer factually correct? Does it contain errors? |
| **Simplicity** | Is it appropriate for a 5-year-old? Does it use simple language and analogies? |
| **Completeness** | Does it fully answer the question? Does it cover the key points? |
| **Clarity** | Is it easy to follow? Does it flow well? |

---

## Scoring Rubric

### Accuracy (1-5)

| Score | Description |
|-------|-------------|
| **5** | All facts correct, no errors |
| **4** | Mostly correct, minor factual issues |
| **3** | Some facts correct, some wrong |
| **2** | Mostly incorrect |
| **1** | Completely wrong or nonsensical |

**Example:**
- Question: "Why is the sky blue?"
- Score 5: "The sky appears blue because sunlight scatters off molecules in the atmosphere, and blue light scatters more than other colors."
- Score 1: "The sky is blue because the ocean reflects into it." (Incorrect)

---

### Simplicity (1-5)

| Score | Description |
|-------|-------------|
| **5** | Perfect for a 5-year-old, uses relatable analogies |
| **4** | Good, mostly simple language |
| **3** | Okay, some complex concepts |
| **2** | Too technical, hard for a child to follow |
| **1** | Not suitable for children at all |

**Example:**
- Question: "How do computers work?"
- Score 5: "A computer is like a really fast helper that follows instructions. Just like you follow steps to make a sandwich, a computer follows steps to solve problems!"
- Score 1: "Computers use binary logic gates and transistor-based processing architectures to execute machine code instructions." (Too technical)

---

### Completeness (1-5)

| Score | Description |
|-------|-------------|
| **5** | Fully answers the question, covers all key points |
| **4** | Good coverage, minor gaps |
| **3** | Covers main points but misses some details |
| **2** | Incomplete, significant gaps |
| **1** | Barely addresses the question |

**Example:**
- Question: "Why do we dream?"
- Score 5: Explains memory consolidation, emotional processing, and brain maintenance.
- Score 2: Only mentions "it helps your brain rest" without elaborating.

---

### Clarity (1-5)

| Score | Description |
|-------|-------------|
| **5** | Very clear, engaging, easy to follow |
| **4** | Clear and understandable |
| **3** | Understandable but some confusion |
| **2** | Hard to follow |
| **1** | Confusing or unclear |

**Example:**
- Question: "What is gravity?"
- Score 5: Uses a clear analogy (like a trampoline or magnet) with smooth flow.
- Score 1: Jumps between ideas without connection, hard to follow.

---

## Optional: Notes

After scoring, you may add notes about:
- Why you preferred one answer over the other
- Any issues with clarity, accuracy, or style
- General observations
